Политика конфиденциальности Memory Galaxy
Дата вступления в силу: 27 марта 2025 г.
1. Сбор данных
Приложение Memory Galaxy не собирает, не хранит и не передаёт никакие персональные данные пользователей. Приложение работает полностью в автономном режиме и не требует подключения к интернету.
2. Данные на устройстве
Приложение не сохраняет никакие данные на устройстве пользователя, кроме стандартной работы операционной системы Android.
3. Сторонние сервисы
Приложение не использует сторонние сервисы, аналитику, рекламные сети или SDK, которые могли бы собирать данные пользователей.
4. Дети
Приложение безопасно для детей любого возраста. Мы не собираем данные ни от каких пользователей, включая детей.
5. Изменения политики
В случае изменения политики конфиденциальности обновлённая версия будет опубликована на этой странице.
6. Контакты
По вопросам конфиденциальности: severivax@yandex.ru
